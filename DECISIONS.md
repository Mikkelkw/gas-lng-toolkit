# Decisions

One line each: date, decision, reason.

- 2026-11-21: Astro 7 + @astrojs/preact + Observable Plot, static output. Matches SPEC section 6.
- 2026-11-21: Site deployed by direct upload to Cloudflare Pages with `wrangler pages deploy`, using the API token from `.env` locally. Matches CLAUDE.md.
- 2026-11-21: Automated deploys deferred to the daily/refresh workflow in phase 8; phase 1 CI runs tests and build only. Keeps phases in SPEC order.
- 2026-11-21: Local Windows note: run Vitest from a `C:\` (upper-case) path; a lower-case `c:\` cwd loads Vitest twice and fails. CI on Linux is unaffected.
- 2026-11-21: Pipeline run as a package (`python -m pipeline.<module>`) from repo root, with a repo-root `.venv` locally. Keeps imports simple and consistent with CI.
- 2026-11-21: Pages project created with `wrangler pages project create --force`. Wrangler 4.166 otherwise redirects Pages commands to Workers; SPEC names Cloudflare Pages. Wrangler confirms `--force` is needed only once, at creation.
- 2026-11-21: Added `site/wrangler.toml` with `pages_build_output_dir = "./dist"` so wrangler treats `site/` as a Pages project.
- 2026-11-21: Cloudflare token can deploy Pages but cannot read user details (`wrangler whoami` fails). Not needed, so left as is.
- 2026-11-21: ">10% change" flag in phase 2 read as "public sources disagree by more than 10%", since no assumptions.json existed to compare against. Flags listed in data/assumptions_sources.md.
- 2026-11-21: TTF and JKM defaults stored as indicative round numbers from public press reports (EUR 85/MWh, $27/MMBtu), labelled manual and user-editable. JKM labelled "North Asia spot LNG (JKM proxy)". No licensed assessment or exchange feed is fetched or stored (hard rule 1).
- 2026-11-21: Canal fee per transit = average of laden and ballast toll, applied twice per round trip, so the SPEC formula "canal fees (both ways)" stays a simple 2 x fee.
- 2026-11-21: Tokyo Bay used as the North Asia reference port for all three Asia routes.
- 2026-11-21: Cargo MMBtu = full vessel capacity x conversion factor; heel and fill limit ignored. Documented simplification.
- 2026-11-21: ECB API docs (data.ecb.europa.eu/help) returned HTTP 503 on 2026-11-21. EUR/USD default taken from the ECB reference-rate web page; API endpoint to be confirmed from docs in phase 5.
- 2026-11-21: Breakeven JKM solved in closed form (netback linear in JKM per route); breakeven charter rate by bisection, valid because the arb falls monotonically with charter rate.
- 2026-11-21: Netback page reads optional `site/public/data/market.json` at build time for Henry Hub and EUR/USD; falls back to assumptions.json. Newer valid values only.
- 2026-11-21: URL updates live with replaceState, so the address bar is always the shareable scenario; "Copy link" copies it.
- 2026-11-21: Breakeven charter rate shown rounded to the nearest $100/day; finer precision would be false precision.
- 2026-11-21: Site is light-theme only, per SPEC "dark-on-light" visual style.
- 2026-11-21: EUR/USD from the ECB's documented eurofxref-hist-90d.xml download, not the Data Portal API, whose docs were unavailable (HTTP 503).
- 2026-11-21: Temperature basket: 16 cities in the 12 largest EU gas-consuming countries (91.4% of 2024 demand), country weight = Eurostat 2024 inland consumption share, split equally between cities where a country has two. Simplification noted in city_weights.json.
- 2026-11-21: History starts 2015-10-01 (10 full winters before 2025/26). Daily refresh re-fetches 45 days to pick up revisions and merges onto stored JSON in site/public/data/.
- 2026-11-21: Observed temperatures = Open-Meteo archive, with days after the archive end filled from the forecast API's past_days analysis.
- 2026-11-21: Validation rejects truncated history (start later than 2015-10-08), gaps over 3 days in the last 400 days, stale data, and shrinking history. Added after a live run once returned only 900 days.
- 2026-11-21: Model fitted on the last 5 complete winters, not all 10. Smallest back-test error of the windows tried (all 10, last 5, post-2022) and reflects the post-2021 supply mix. Meets SPEC minimum of 5.
- 2026-11-21: LNG deviation in projections = recent 30-day average send-out x scenario %, i.e. the recent average stands in for the winter average.
- 2026-11-21: Normal weather = each of the last 10 winters' temperature for that calendar day, shifted by the scenario offset, converted to HDD per year, then averaged. Forecast days use the forecast unshifted.
- 2026-11-21: Demand response cuts daily net withdrawal by % x average EU daily demand (AGSI EU annual consumption / 365). Simple and explainable; ignores seasonality of demand.
- 2026-11-21: Presets: Normal (0 C), Cold winter (-2 C), Cold + LNG shortfall (-2 C, -20% LNG), Mild (+2 C).
- 2026-11-21: Projection logic exists in Python (back-test) and TypeScript (site). A parity case in model.json is checked by both test suites so they cannot drift.
- 2026-11-21: Storage page payload computed at build time (current winter, range, normals, forecast) rather than shipping full history to the browser. Daily rebuild keeps it current.
- 2026-11-21: Daily workflow fails visibly (red run, GitHub email) when any source fails, but only after committing and deploying the last good data. Partial failure never blocks the deploy.
- 2026-11-21: Wrangler pinned to 4.166.0 in CI for reproducible deploys.
- 2026-11-21: Redirects as Cloudflare Pages `_redirects` (true 301s), not meta-refresh pages.
- 2026-11-21: Canonical URLs use the trailing-slash form Cloudflare serves (e.g. /lng-netback-calculator/).
- 2026-11-21: No Open Graph image in v1 (twitter:card summary); suggested for v1.1.
- 2026-11-21: Primer cites EIA (2020 cancellations: ~46 in June, ~50 in July) and the Council of the EU (2025 storage rule amendments) for its only time-sensitive facts.
- 2026-11-21: Storage likely range = projection ± back-test error in pp of working gas volume, using the larger of the actual-weather and normal-weather errors for each back-test start date. Reason: the normal-weather run is the real forecast case, but on 1 Jan the actual-weather error was larger, so taking the larger is the cautious choice.
- 2026-11-21: Range width is interpolated linearly by days left to 31 March (zero on 31 March, flat beyond the 1 October horizon). Reason: error grows with horizon in the back-test (1.5, 3.3, 5.5 pp at 90, 151, 182 days), and a fixed width would overstate uncertainty late in winter.
- 2026-11-21: Range is symmetric and the projection is not bias-corrected; the 2025/26 low bias is stated in one line instead. Reason: owner instruction, and one winter is too little to estimate a bias.
- 2026-11-21: The range is called a "likely range", not a confidence interval, and the method text says it rests on one winter's back-test. Reason: avoid implying statistical coverage it does not have.
- 2026-11-21: Lift/cancel margin = FOB netback − feedgas multiplier × Henry Hub (liquefaction fee sunk). The existing margin column is renamed "Full-cost margin". The no-margin warning now says whether lifting still beats cancelling.
- 2026-11-21: Manual price notice uses the older of the TTF and JKM "as of" dates and the viewer's UTC date; amber with a "Check prices:" label after 7 days, so the meaning is not colour alone.
- 2026-11-21: The price notice renders only after the island mounts. Reason: Preact hydration does not patch attributes, so a server-rendered notice kept its non-amber class when the viewer's date differed from the build date.
- 2026-11-21: Redesign (SPEC 11.1). Text contrast on paper: teal (2.95:1) and brass (2.13:1) are never used for text on light backgrounds, only for chart marks, fills and rules. Text uses ink (13.5:1), muted #4E5A66 (6.3:1), ocean blue for links (11:1) and signal red (4.8:1). On navy: paper (14.8:1), #B8C4D0 (9.4:1), brass (6.9:1).
- 2026-11-21: Chart palette checked with the dataviz validator on the paper surface: colour-blind separation passes (ΔE ≥ 31). Teal and brass are below 3:1 against paper, so every chart keeps direct labels, a legend and a table view. Ocean blue is used as a neutral reference (previous-winter band and average), not a series hue.
- 2026-11-21: Fonts self-hosted with Fontsource (latin subset only): Fraunces 600 for headings, Inter 400/600 for body, IBM Plex Mono 400/500 for numbers and inputs. Inter 400 and Fraunces 600 are preloaded. About 96 KB of woff2 in total.
- 2026-11-21: Hero map is original: Natural Earth 1:110m land (public domain, via the world-atlas package) and simplified waypoint routes, projected to Mercator by site/scripts/build-map.mjs. The map spans 389° of longitude so all four routes draw unbroken; Tokyo appears at both edges and the caption says so.
- 2026-11-21: Map land ships as a static, cached SVG (16.6 KB gzipped) loaded as an image; only the routes (3.6 KB) are inline, so they can animate. No map library in the browser.
- 2026-11-21: Map route lines draw in once with a CSS mask animation, only under prefers-reduced-motion: no-preference. In-map labels are hidden below 600 px wide, where they would be unreadable; the HTML key under the map names every route.
- 2026-11-21: Landing page live figures are computed at build time by src/lib/home.ts (tested). The daily refresh rebuilds the site, so they stay current. Each figure shows its date; the netback figure is dated by its oldest price input.
- 2026-11-21: The projected 31 March figure on the landing page uses the same Normal run and likely range as the storage tool. Outside October to March it says the projection restarts on 1 October.
- 2026-11-21: Primary buttons are brass on navy in the hero (6.9:1) and navy with a brass underline on paper; active preset chips and the current nav item carry brass as the active state.
- 2026-11-21: Custom domain (SPEC 11.3): canonical origin https://lngtoolkit.com everywhere (Astro site, canonical tags, Open Graph, sitemap, robots.txt). Site renamed to "LNG Toolkit"; repo and Pages project names unchanged.
- 2026-11-21: *.pages.dev (all hosts, including preview and deployment-hash URLs) and www.lngtoolkit.com 301 to the apex via site/functions/_middleware.ts, keeping path and query string. Rules live in src/lib/redirects.ts (tested). Reason: SPEC 11.3 names this approach, and the deploy token has no rights for Cloudflare's recommended Bulk Redirects.
- 2026-11-21: Old /netback and /storage redirects moved into the middleware too, in one hop with the host fix. Reason: Cloudflare docs say _redirects rules are not applied to requests served by Pages Functions. public/_redirects is kept as a fallback for when Functions do not run.
- 2026-11-21: Known cost of the middleware: every request now invokes a Pages Function, which counts against the Workers free plan (100,000 requests/day, shared with Workers). Ample for this site. Owner may want "Fail open" set under Settings > Runtime so static pages still serve if the quota is ever hit.
- 2026-11-21: Verified with a preview deploy (branch redirect-test) before production: wrangler compiled site/functions from the deploy directory, and 301s kept path and query string.
- 2026-11-21: Deliverability constraint zone below 20% full on the storage chart, with the owner's note when a projection ends at or below 20%. The 20% level is an owner assumption, labelled indicative on the site; the mechanism is cited to EIA ("The Basics of Underground Natural Gas Storage"). An S&P Global news report quotes analysts calling an end-of-winter level under 20% risky, consistent with the threshold. The preset table marks presets ending in the zone.
- 2026-11-21: Likely range made asymmetric from the signed back-test errors of both runs: room below = largest over-prediction of storage, room above = largest under-prediction, each interpolated by days left. Each side has a floor of the fit RMSE carried to 31 March (100 x 1.36 TWh/d x sqrt(days) / WGV), so a side the single back-test never missed on is not zero width. Projection still not bias-corrected. The one-sentence explanation is generated from the data, so it stays true if a future back-test changes sign.
- 2026-11-21: Hero map place names moved from inline SVG text into a static image (public/map/labels.svg), with the SVG named by <title> and described by <desc>. Reason: aria-hidden alone hides labels from screen readers but leaves them in copied and extracted page text, which the owner wanted gone.
- 2026-11-21: "JKM-TTF spread" hyphenated in the netback intro, the netback meta description and the primer, for consistency.
- 2026-11-21: CI deploy job now checks out the repo and deploys from site/, so wrangler uploads site/functions. Before this, CI deployed only the dist artifact and the middleware was missing in production (found by checking the live site after deploy).
